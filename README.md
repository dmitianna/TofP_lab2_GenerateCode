# TofP_lab2_GenerateCode
# 1. Постановка задачи

В исходной реализации была предусмотрена генерация программного кода только для языка C++.
Требовалось расширить существующую архитектуру таким образом, чтобы обеспечить генерацию кода ещё и для языков **C#** и **Java**.

Для решения поставленной задачи необходимо было:

* реализовать поддержку генерации кода для языков C++, C# и Java;
* использовать паттерн проектирования **«Абстрактная фабрика»** для создания языкозависимых элементов программы;
* добавить поддержку модификаторов классов и методов, специфичных для C# и Java;
* обеспечить корректную генерацию синтаксических конструкций для каждого языка;
* исключить возможность формирования некорректного кода посредством механизма валидации модели;
* сохранить возможность дальнейшего расширения системы новыми языками программирования.

Сгенерированные программы должны соответствовать синтаксису целевого языка и не содержать конструкций, отсутствующих в нём.

# 2. Предлагаемое решение

Для решения поставленной задачи был выбран порождающий паттерн проектирования **«Абстрактная фабрика» (Abstract Factory)**.

Использование данного паттерна позволяет создавать семейства взаимосвязанных объектов, представляющих элементы программного кода, не привязывая клиентский код к конкретному языку программирования.

В рамках проекта были реализованы три семейства:

* C++;
* C#;
* Java.

Для каждого языка реализовать собственные версии:

* класса (`ClassUnit`);
* метода (`MethodUnit`);
* оператора вывода (`PrintOperatorUnit`).

Выбор конкретной реализации осуществляется через соответствующую фабрику:

* `CppGeneratorFactory`;
* `CSGeneratorFactory`;
* `JAVAGeneratorFactory`.

Таким образом клиентский код работает только с абстрактными интерфейсами и не зависит от особенностей конкретного языка программирования.


# 3. Обзор исходного кода

### Основные файлы проекта

#### factories.h

Содержит определение абстрактной фабрики `AbstractFactory` и её конкретных реализаций:

- `CppGeneratorFactory`
- `CSGeneratorFactory`
- `JAVAGeneratorFactory`

Каждая фабрика отвечает за создание языко-зависимых элементов синтаксического дерева программы.

#### unit.h

Содержит определение абстрактного базового класса `Unit`, который является основой для всех элементов синтаксического дерева. Класс определяет интерфейс генерации кода (`compile()`), добавления вложенных элементов (`add()`) и проверки корректности конструкции (`validate()`).

#### classunit.h

Содержит определение абстрактного класса `ClassUnit`, представляющего программный класс. Обеспечивает хранение имени класса, модификаторов и вложенных элементов.

#### methodunit.h

Содержит определение абстрактного класса `MethodUnit`, представляющего метод класса. Класс хранит имя метода, тип возвращаемого значения, модификаторы и тело метода.

#### printoperatorunit.h

Содержит определение абстрактного класса `PrintOperatorUnit`, предназначенного для генерации операторов вывода текста.

### Реализации для языков программирования

#### C++

- `CPPClassUnit`
- `CPPMethodUnit`
- `CPPPrintOperatorUnit`

#### C#

- `CSClassUnit`
- `CSMethodUnit`
- `CSPrintOperatorUnit`

Дополнительно реализована поддержка модификаторов C#, таких как `abstract`, `sealed`, `virtual`, `extern`, `internal`, `protected internal`, `private protected` и других.

#### Java

- `JAVAClassUnit`
- `JAVAMethodUnit`
- `JAVAPrintOperatorUnit`

Реализована поддержка модификаторов Java, включая `abstract`, `final` и `static`, а также проверка допустимости их комбинаций.

Пример использования:

```cpp
CppGeneratorFactory factory;

auto myClass = factory.CreateClassUnit("MyClass");

myClass->add(
    factory.CreateMethodUnit(
        "testFunc1",
        "void",
        0
    ),
    AccessModifier::PUBLIC
);

std::cout << myClass->compile() << std::endl;
```

## Инструкция по использованию

### Выбор языка программирования

Создайте экземпляр фабрики для требуемого языка:

```cpp
CppGeneratorFactory cppFactory;
CSGeneratorFactory csFactory;
JAVAGeneratorFactory javaFactory;
```

### Создание класса

```cpp
auto myClass =
    factory.CreateClassUnit("MyClass");
```

### Добавление методов

```cpp
myClass->add(
    factory.CreateMethodUnit(
        "testFunc1",
        "void",
        0
    ),
    AccessModifier::PUBLIC
);
```

### Добавление операторов вывода

```cpp
auto method =
    factory.CreateMethodUnit(
        "printMessage",
        "void",
        MethodModifier::STATIC
    );

method->add(
    factory.CreatePrintOperatorUnit(
        "Hello, world!"
    )
);
```

### Генерация кода

После формирования структуры программы необходимо вызвать метод `compile()`:

```cpp
std::string program =
    myClass->compile();
```

### Вывод результата

Сгенерированный код возвращается в виде строки и может быть выведен:

```cpp
std::cout << program << std::endl;
```

### Покрытие тестами

Тесты охватывают следующие аспекты работы проекта:

- генерацию кода для C++, C# и Java;
